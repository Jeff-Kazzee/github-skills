# Security policy

## Report a vulnerability

Report a vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/{{owner}}/{{repo}}/security/advisories/new).
Do not open a public issue, pull request or discussion about it.

Include what you did, what you saw, the affected version or commit, and how bad
you think it is.

## What happens next

- You get a first reply within {{days to first reply}} days.
- We confirm or rule out the problem, and tell you which versions it affects.
- We fix it, publish a GitHub security advisory, and credit you unless you ask
  us not to. We aim to disclose within {{days to disclosure}} days of your report.
